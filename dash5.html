Monte o palco físico em metros: arraste as telas, cantos = tamanho (Shift = proporção), elas grudam nas bordas umas das outras (Alt = sem ímã). O contorno delas é o canvas; cada tela mostra a parte dela. Com telão (pixel map) cada tela sai no bloco dela do raster.
O telão chega como uma imagem só (a resolução que ele anuncia). Diga onde cada tela entra no raster, como a processadora espera: grade ou desenhar; arraste/redimensione em px (Alt = solto); ↻ = painel deitado. Fora dos blocos sai preto.
Cada SAÍDA do patch é um retângulo no palco (como as slices do Resolume: uma saída num painel do telão, outra no projetor). Arraste, cantos = tamanho (Shift = proporção), Alt = sem ímã; encaixar numa tela = a lista ao lado. 2 cliques numa saída = entrar: o lugar de cada entrada dentro dela (2 cliques numa entrada = ela inteira). Ao fundo: o palco pronto, ao vivo.
