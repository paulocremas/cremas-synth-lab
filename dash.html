Mídia — imagens e vídeos como fonte de imagem

No dropdown image do topo, Media é uma fonte só; qual item toca se escolhe aqui (clique) ou por tecla (engrenagem → vincula; vale na janela do native_synth e em qualquer lugar do dash). Vídeo roda em loop. preencher = cobre o output cortando o excesso; desmarcado = encaixa inteiro com barras. set = "pasta"; os atalhos valem só no set selecionado. Arquivos em media/; grava MEDIA / MEDIA_SET(S) / MEDIA_KEYS em tuning.py.

Transições — como entrar em cada mídia

Arquivos .glsl em transitions/ (estilo gl-transitions: uma vec4 transition(vec2 uv) com getFromColor/getToColor/progress; cabeçalho // ms: N = duração). Na troca de mídia, um passe GPU mistura a imagem que sai com a que entra e alimenta o shader normal — o preset nem sabe. Cada item da galeria de mídia acima escolhe a sua (ou (padrão) / corte seco). Grava TRANSITION_DEFAULT + o campo transition de cada item de MEDIA.

padrão

Shader ativo — galeria de presets

Arquivos .frag em shaders/: image.frag (base) + presets/<set>/*.frag — cada set é uma subpasta. Clicar troca ao vivo. A engrenagem de cada preset: renomear, apagar, e vincular uma tecla (vale só no set ativo, na janela do native_synth ou no dash). Grava SHADER / SHADER_SET / SHADER_KEYS.

Potenciômetros de efeito — grava em tuning.py (FX)

Um por efeito nomeado no cabeçalho // fx: do shader ativo. 0 = desligado, 1 = cheio. O shader multiplica a intensidade de cada efeito por u_fx_<nome>. Um controlador MIDI vai poder mexer nesses mesmos valores quando for ligado (ainda não implementado).
